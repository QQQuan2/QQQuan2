# Tiny Island — 交付报告（V2）

> Build a little world of your own.
> 一个漂浮在海上的低多边形迷你岛屿：可旋转探索、切换昼夜、放置装饰、点击邮箱写日记，日记会让岛屿慢慢长大。
>
> **V2（2026-11-23）**：小屋从「可看的模型」变成「可进入的空间」，岛屿从「可旋转的场景」变成「可探索的世界」。本轮全部功能已在真实浏览器里跑通并逐项验收，详见 [§8 V2 实机验收](#8-v2-实机验收2026-11-23)。

## 1. 运行方式与入口文件

**必须用本地 HTTP 服务打开**（项目使用 ES modules，不能 `file://` 双击 html）。

| 方式 | 操作 |
| --- | --- |
| A（Windows 最简单） | 双击 `start.bat`，会自动打开 `http://localhost:8000` |
| B（命令行） | 在本目录执行 `python -m http.server 8000`（或 `py -m http.server 8000`、`npx serve .`），浏览器访问 **http://localhost:8000** |

- **入口文件：`index.html`**
- 无需联网、无需 `npm install`、无需账号/后端。Three.js r160 已放在 `vendor/`，通过 importmap 引用，完全离线可运行。
- 推荐 Chrome / Edge，1366×768 及以上（已做投屏适配）。
- 当前会话中已启动预览服务：**http://127.0.0.1:8000/index.html**（如端口被占用，停掉后重新运行上面的命令即可）。

## 3. 已实现功能

**视觉**
- 不规则轮廓的悬浮岛（非圆盘/平面），12 层渐收的分层岩石岛底 + 24 块凸出巨石
- 视觉中心小屋：曲面瓦片屋顶、半木结构斜撑、拱形发光窗与窗棂花箱、门廊雨棚、山墙圆窗、老虎窗、铜门把手、台阶、烟囱 5 团循环飘烟、门灯
- 弯曲石板步道、池塘（睡莲/芦苇/卵石）、木码头与带帆小船、花园、栅栏、3 盏路灯
- 四种树形（圆冠 / 松 / 秋色 / 发光记忆树）、花簇、岩石、草丛（InstancedMesh 130 株）
- 自定义 shader 天空（三段渐变 + 地平线辉光）与动态海面（顶点正弦浪、浪峰、日照/月光带、环绕浪花圈、同心波纹、远景雾化）
- 漂移的云、夜晚星空（460 颗、固定像素尺寸）、ACES 色调映射 + PCF 软阴影（2048 shadow map）
- UI：左上品牌、右侧玻璃控制面板、底部提示、纸张质感日记弹层；全站线性 SVG 图标，无 emoji

**交互**
- 拖动旋转 / 滚轮缩放 / 阻尼平滑 / 极角与距离限制 / 轻微自动旋转（首次按下画布即停止）/ Reset View
- Day / Sunset / Night：天空、雾、半球光/环境光/主光颜色与强度、海色、浪花高光、窗光、路灯、门灯、星空、曝光全部联动平滑过渡
- 装饰模式：Tree / Flowers / Rock / Lantern 四个工具，实时半透明幽灵预览（绿色合法 / 红色非法），禁区判定（房屋、池塘、邮箱、码头、固定树木、岛外海面）、最小间距、Remove 删除、Reset Decorations
- 日记：点击岛上红色邮箱触发（相机轻微推近）、自动日期、5 种心情、正文（1500 字上限）、保存、历史查看、单条删除、ESC / 关闭按钮 / 点击遮罩关闭、Ctrl+Enter 快捷保存
- 保存反馈：暖光脉冲、岛上浮动记忆星点、左上与面板计数更新
- 成长机制（读取真实 localStorage 条数）：≥1 窗户/邮箱亮起；≥3 花园多出花簇；≥5 出现发光树与更多星光
- 日记 / 装饰 / 氛围全部写入 localStorage，刷新后完整恢复；空状态、非法输入、XSS 转义、存储失败均有处理

**数据键**：`tiny-island.memories.v1`、`tiny-island.decorations.v1`、`tiny-island.atmosphere`、`tiny-island.welcomed.v1`（V2 首次访问标记）。

### V2 新增功能（本轮完成）

**Home —— 可进入的小屋（最高优先级）**
- 点击小屋 → 约 470ms 奶油色淡入淡出过场 → 切换到一个**独立的室内 Three.js Scene**（不是弹窗、不是贴图、不是 2D UI），相机同时切换并收紧轨道限制。
- 室内为程序化低多边形建模：拼花木地板（含暗色底板填缝）、四面墙 + 窗洞/门洞、天花板木梁、护墙板、海景大窗（玻璃 + 窗帘）、窗外 shader 海天渐变 + 远处浮岛剪影 + 日/月精灵 + 70 颗夜星、床与枕头毛毯、边几发光球、书架（随机彩色书本 + 顶上盆栽）、书桌（摊开的日记本 + 笔 + 墨水瓶 + 台灯）、椅子、门、挂画、盆栽、地毯、暖色主光/点光/窗光与阴影。
- 4 个室内交互物：
  - **日记本** → 打开日记，并把相机推近书桌；
  - **窗户** → 相机推近窗边 + 海景文案反馈；
  - **台灯** → 开关室内灯光（关灯会真实压暗环境光/半球光/主光/边几光，开灯恢复暖光）；
  - **门** → 离开小屋回到岛屿。
- 退出方式三种：点击门、右上角 **Leave home**、按 **Esc**；退出后恢复进屋前保存的岛屿视角。

**Mailbox / Dock —— 另外两个探索点**
- 邮箱：保留原有日记全部功能（日期/心情/正文/保存/历史/删除/localStorage 持久化），并可从品牌栏 **Open journal** 直接进入。
- 码头 / 小船：点击后不是完整航行游戏，而是 2.5 秒的轻反馈——相机推向海面、小船沿航向驶出、船身轻摆，随后弹出**随机发现的明信片**（8 段文案之一），点 **Back to shore** 小船返航、相机回位。

**画面与 UI 打磨（不重建）**
- 夜间预设提亮（半球光 0.74 / 环境光 0.38 / 主光 0.9 / 曝光 1.16），实机夜景岛屿、门窗、路灯、星星均清晰可辨。
- 小屋整体缩放 0.9（缩小 10%），与岛体/树/码头比例更协调；屋顶、入口、圆窗细节保留。
- 地形起伏、岩层轮廓、海面渐变与细波、云的形态、光照与材质统一性均沿用已有程序化管线微调。
- UI 走温暖奶油色半透明玻璃风：欢迎横幅、过场淡入、Leave home 药丸按钮、明信片纸张卡片；进入室内时整块岛屿 HUD 淡出，只留出口与底部提示，不遮挡 3D 场景，投屏可读。
- 首次访问显示 **"Welcome to your little world. Take a moment to explore."**，约 5 秒自动淡出且只出现一次；Home / Mailbox / Dock 悬停才显示高亮 + tooltip（Step inside / Leave a memory / Set sail），不留常驻标签。

## 5. 是否使用 Blender

**未使用 Blender** —— 当前环境未安装（`Get-Command blender` 无结果，常见安装路径也不存在）。按需求中的兜底方案采用 **Three.js 程序化建模**，且没有因此停工：

- 岛体草地/岩层、曲面屋顶、船壳都是自定义 `BufferGeometry`（`TriBuilder` 逐面纯色三角形汤 + `flatShading`），不是基础几何体堆砌；
- 树冠、岩石、云为带空间哈希的扰动多面体，保证顶点焊接；
- 共享 `geo()` / `mat()` 缓存 + InstancedMesh 控制分配；
- 所有模型由种子随机数生成，每次打开世界完全一致；
- 项目不依赖任何外部模型、贴图或在线 API。

## 6. 已知问题 / 限制

- 装饰放置是「选工具 → 点击地面」，不是物理拖拽（按需求刻意简化）。
- 小船 stylized 地浮在云海高度，与低处海面之间是写意衔接而非物理水面。
- 海洋为自定义 shader 波浪，未做真实反射/折射；云为低多边形团块，非体积云。
- 记忆星点最多显示 14 个，更多日记仍影响计数与成长阶段。
- 自动旋转在首次点击画布后停止；切换氛围/工具按钮不会停止自动旋转（有意为之，方便展示）。
- 极窄窗口（< 760px）下右侧面板会压缩，主要面向桌面投屏设计。
- 刷新恢复依赖浏览器 localStorage；换浏览器或清站点数据会回到初始状态。

## 7. 约 1 分钟课堂演示顺序（V2 版）

1. **0–10s｜探索**：打开页面，首次访问欢迎语浮现后自动淡出；让岛屿缓慢自转，展示整体构图；把鼠标依次移到小屋 / 邮箱 / 小船上，看高亮与提示。
2. **10–30s｜进屋**：点击小屋 → 过场 → 进入室内。依次点**台灯**（明显变暗/变暖）、**窗户**（推近看海）、**书桌日记本**（写一句话并保存）、点**门**或 **Leave home** 回到岛上。
3. **30–40s｜出海**：点击码头 / 小船，看小船驶出与随机发现的明信片，点 **Back to shore** 返航。
4. **40–55s｜氛围与装扮**：Day → Sunset → Night（夜景清晰可见），点 Tree / Lantern 放两件装饰再 Reset。
5. **55–60s｜记忆与刷新**：邮箱或 Open journal 写一条记忆，刷新页面，证明日记条数、成长状态与氛围都还在。
   > 想展示成长机制，现场连存 3 篇（花园多花）和 5 篇（发光树出现）；删掉一篇会看到成长实时回退。

### 9.2 实现逻辑

- **连续而非三档跳变**：太阳高度角 ≤ −10° → Night，−10°~0° 由 Night 平滑混合到 Sunset，0°~15° 由 Sunset 平滑混合到 Day，> 15° → Day；用 smoothstep 做权重，再喂给原有阻尼插值管线，因此天空、雾、半球光、主光颜色与强度、海洋色、曝光、星星、窗光、门灯、海面闪光全部连续变化，覆盖 Night→Dawn→Sunrise→Day→Golden Hour→Sunset→Twilight→Night。
- **太阳跟随方位**：设备本地时间（隐含本地时区）+ 经纬度算高度角/方位角，方位角映射到场景坐标（北 = −Z、东 = +X），太阳出地平线后逐渐替换预设光源位置，阴影方向随之变化；地平线以下淡出为原有月光方向。
- **定位与隐私**：只在用户点击 Auto 时才请求 Geolocation；不后台持续定位；经纬度仅存在于内存，**不写入 localStorage、不上传**；拒绝/不支持/超时（8s）时用 `Intl` 时区表或 UTC 偏移推断的默认位置，并明确 toast 提示「using a default location」。刷新后若 Auto 仍启用，仅在权限已是 granted 时静默取一次定位，否则直接用默认位置并提示。
- **刷新机制**：进入 Auto 与页面加载时立即计算；`update()` 中每 30 秒重算一次太阳位置（不在每帧跑天文计算），所有参数由既有 damp 平滑逼近，跨越日出日落不会突跳。

### 13.2 纸张纹理的具体实现

- **不使用任何图片资源**。纹理是内联 SVG `feTurbulence fractalNoise`（120×120、`baseFrequency=0.9`、`numOctaves=2`）以 data URI 存进 `--paper-noise`，平铺时单块仅约 200 字节，不产生网络请求，不影响 Three.js 帧循环。

## 14. Growth 1.1 — Milestone A（岛屿成长系统）

> 记忆让岛屿真正长大：累计记忆数驱动 5 级地形扩张与景观解锁，删除不会让岛屿倒退。

### 14.1 设计决策

**① 扩张环带（skirt），不是整体缩放。** 原始岛体、小屋、邮箱、步道、池塘、码头全部零改动（坐标与尺寸不动）。新增参数化「草地台地 + 平移岩层裙」从原岛外缘向外生长：内缘严格贴合 `edgeRadius(a)` 与 `topHeight(a,1)` 无缝衔接，外缘用 `edgeWobble(a)` 做不规则轮廓。裙边顶点用闭包拓扑表 `V: (W)=>[x,y,z]` 预分配，平滑过渡（damp 收敛）时按阈值重填顶点 + `computeVertexNormals`。`W < 0.02` 时整组隐藏，保证 Lv.1 与旧版逐像素一致（零回归、无 z-fighting）。

**② 累计计数状态机（lifetime），不是便条数。** `tiny-island.growth.v1` 存 `lifetime / countedIds / milestones / unlocks / placements / effects`。只有「成功创建全新记忆」且 id 未被计入才 +1（幂等防重复）；编辑、改心情、查看历史、删除、超时修订都不加。首屏 `sync(ids)` 静默补标记（老用户零迁移）。**删除不会减少 lifetime**，岛屿永不缩小。

**③ 解锁（unlocks）≠ 摆放（placements）。** 里程碑只授予「可以放某类景观」的资格（Permanent Unlock），树/花/石/灯不再随日记自动增加——岛屿长得慢而真实，景观由用户在装饰模式里自行建设。B/C 预留接口：`getUnlocks / isUnlocked / getPlacements / placeLandscape / removeLandscape / setEffectEnabled / subscribe`。

**④ 海面浪花圈跟随扩张。** world.js 海面 shader 新增 `uShore` uniform，`shoreRadius() = 11.0 + (s-1)*ISLAND_R`，浪花始终拍在新岸线上（s=1 时恒为 11.0，零回归）。

**⑤ 成长反馈分级。** 日常新建记忆 = 轻量反馈（波纹环 + 12 个火花 Sprite，按 nightLevel 调日/夜配色，不生成任何永久景观）；10/25/50/100 里程碑 = 地形扩张动画 + 等级卡片 + 解锁展示，触发时立即持久化（刷新不重播），可 Skip 立即到位。

**⑥ 插值与平滑。** `scaleFor(n)` 分段线性 5 节点（0→100%、10→110%、25→125%、50→145%、100→160%，100 后封顶），`damp` 平滑收敛（扩张 1.3 / 收缩 3.0），实测 0→50 全程无跳变。

| 文件 | 改动 |

## 15. Local Profile System 1.0（本地个人档案）

> 同一台设备上多个完全独立的小岛；现有数据无损迁入默认档案。

### 15.1 现有数据检查结论

- 存储方式：**全部 localStorage**，无 IndexedDB / sessionStorage / 服务端，无多个旧版本键名。
- 7 个用户数据键：`memories.v1`（含 `revisions` 修订历史与心情快照）、`moods.v1`、`diarySettings.v1`、`decorations.v1`、`growth.v1`、`welcomed.v1`、`atmosphere`（**无版本后缀**）。
- 读写点：`diary.js` / `decorations.js` / `growth.js` / `atmosphere.js` / `main.js`；全部同步即时写入，唯一的「未保存数据」是日记编辑器里尚未保存的草稿。
- 公共资源（vendor/ 里的 Three.js、程序化几何/材质、代码）天然共享，不按档案复制。

### 15.2 架构决策

**① 零重构 + 快照交换。** 7 个旧键保持为「当前档案的活动工作区」，现有模块读写代码**一行未改**。新增 4 个系统键：

| 键 | 内容 |
| --- | --- |
| `tiny-island.profiles.v1` | 索引 `{version, activeId, profiles:[{id,name,createdAt,lastUsedAt}]}` |
| `tiny-island.p.<id>.v1` | 每个档案一份快照 `{ "<旧键后缀>": "<原始字符串>" }`，**逐字节保真**（修订历史、心情快照、解锁状态原样保留） |
| `tiny-island.profile.switch.v1` | 切换崩溃安全标记（两阶段） |
| `tiny-island.migration.backup.v1` | 迁移前全量备份，**永不删除** |

**② 切换 = 快照交换 + 整页 reload。** 每个档案是独立的 localStorage 键，物理隔离；切换后页面重建，Three.js 场景、装饰、成长系统全部从目标档案数据重新构建——**不可能残留上一档案的任何场景对象**。localStorage 全同步，无异步读写竞争，无「延迟保存覆盖切换后档案」问题。

**③ 崩溃安全与数据权威。** 旧键永远是最新数据：正常启动把旧键 flush 回当前档案 blob；切换按「flush 旧 → 写标记 → 写目标 blob 到旧键 → 发布索引 → 清标记 → reload」顺序执行，中途断电/强关后 `initProfiles()` 依标记把目标 blob 恢复到旧键。全部关键点做**写入校验 + 失败回滚**（flush/swap 字节级验证、索引读回校验），失败明确 toast 提示且不破坏任何一方数据。

**④ 迁移幂等。** 索引键存在即视为已迁移，直接加载；不存在时：备份旧数据 → 写默认档案 blob → **逐字节验证** → 通过才发布索引。旧键从不被清除或覆盖（默认档案直接沿用它们），备份写入失败则中止启动并提示，原始岛数据不动。

**⑤ 新档案 = 空白快照 `{}`。** 恢复空快照会删除 7 个旧键 → 0 记忆、Lv.1 初始岛屿、默认 Day 天色、欢迎横幅重现、成长从 0 开始，不继承任何装饰/设置。至少保留一个档案：最后一个档案不显示删除入口；当前档案不提供删除入口（需先切换或新建）。

**⑥ 未保存草稿保护。** 日记打开时切换/新建会被拦截并提示「先保存或关闭日记」，不静默丢弃编辑内容。

## 19. M2r1 — 整套 ESM 模块 `?v=` 版本化（缓存根治）

### 19.1 背景与目标

`http.server`（以及部分静态托管）不带 `Cache-Control`，浏览器会对 ESM 模块做启发式缓存，导致改完代码后用户浏览器长期跑**旧的模块图**——这是历次"功能没生效 / fade 卡死"假象的头号来源（见 `DIAGNOSIS-tiny-island.md`）。此前一直靠 `close`+`open` 或 `Ctrl+Shift+R` 硬刷新绕开。

关键点：**只给入口 `main.js` 加 query 无效**，因为 `main.js` 里 `import './world.js'` 等仍是裸路径，会被各自缓存；必须让**整套 ESM 子模块图**都带同一个版本号。

### 19.2 改动

| 范围 | 内容 |
| --- | --- |
| `index.html` | 入口 `<script type="module" src="./js/main.js?v=20261127a">` |
| 12 个 `js/*.js` | 所有相对 `import ... from './xxx.js'` 与 `../vendor/OrbitControls.js` 统一追加 `?v=20261127a`（含多行 import 的结尾 `} from '...'`） |
| `vendor/three.module.js` | **不加**（由 importmap 映射到固定 vendored 引擎，r160 不变，课堂要求离线可跑） |

版本号统一为 `20261127a`。**发版约定**：以后每次发布，只需全仓把 `v=20261127a` 整体替换成新值，浏览器即会重新拉取整套模块图，不再依赖硬刷新。

### 19.3 实机验收（Chromium / localhost:8123）

- `performance.getEntriesByType('resource')` 检查：首次加载与 `open` 重载**均 15/15 个 `/js/` 请求带 `?v=20261127a`**，`unversioned:[]`，`__bootError` 为空、`world.outsideRT` 就位。
- 全链路回归：合成点击进屋 → `data-mode=interior`、相机切到室内机位 → 截图 `preview/m2r1-versioned-interior.png`（窗外实时岛景、Japandi 家具完好）→ `Leave home` → `data-mode=island`、`house.group`/`mailbox` 可见性还原、`fade` opacity 归零、零启动错误。
- 静态零告警（`read_lints`）。

### 19.4 边界说明

入口 HTML 本身若被强缓存，用户仍可能需要一次普通刷新才能拿到新的 query 串（GitHub Pages 等正规静态托管带正确缓存头时无此问题）；但**子模块图已彻底摆脱启发式缓存**。此前的 `close`+`open` 验证法仍可作为兜底继续沿用。
