<details>
<summary>📜 A slightly longer story</summary>

<br/>

I started by breaking a lot of small things and learning how they fit back together. These days I mostly build tiny full-stack apps to scratch my own itch — usually Flask on the backend, a sprinkle of JS on the front, and SQL when things need to persist.

I learn faster when I ship something ugly than when I plan something perfect, so most of what you'll find here is the "shipped version" of an idea rather than a polished showcase. The 77-test smoke suite on the delivery project is the closest thing I have to a "I'm serious about this" badge.
